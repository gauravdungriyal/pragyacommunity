What this is

Every action defined in the Pragya Yog API workbench, called against the live api.php with the exact request body the workbench sends. Each entry records what actually came back, not what the documentation predicts.

Actions that create real records — bookings, payments, reviews, tickets, device registrations and favourite toggles — are listed but were deliberately not called, so no live data was written. Endpoints marked Auth required were confirmed to reject an invalid token; their response shapes are unverified because no test account was available.
